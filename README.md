E-Commerce Sales SQL Analysis
Project Overview

This project analyzes an e-commerce sales dataset using SQL Server.

The goal is to identify sales trends, customer spending patterns, product performance, and revenue by category and city.

Tools Used

- SQL Server
- SQL
- GitHub

Database Tables

The database contains four tables:

- Customers
- Products
- Orders
- Order Items

Business Questions

The analysis answers questions such as:

1. What is the total revenue?
2. How many orders were placed?
3. Which products sell the most units?
4. Which products generate the most revenue?
5. Which product categories generate the most revenue?
6. What is the average order value?
7. Which customers spend the most?
8. How does revenue vary by month?
9. Which cities generate the most revenue?
10. Which products have sold more than 5 units?

SQL Skills Demonstrated

- SELECT
- JOIN
- GROUP BY
- ORDER BY
- WHERE
- HAVING
- Aggregate functions
- SUM()
- COUNT()
- MONTH()

Project Files

- `Database.sql` — database, tables, and sample data
- `analysis_queries.sql` — SQL analysis queries

Key Findings

- Total revenue: ₹30,462
- Total orders: 12
- Best-selling product by units: Notebook
- Highest-revenue product: Headphones
- Highest-revenue category: Electronics
- Average order value: ₹2,538.50

## Conclusion

The analysis demonstrates how SQL can be used to transform transactional e-commerce data into useful business insights about products, customers, cities, and revenue trends.
